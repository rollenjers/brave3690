# Команды для работы с git

### Начинает отслеживать файл
```
git init
```

### Показывает текущее состояние гита, есть  ли изменения, которые нужно закоммитить (сохранить)

```
git status
```

### Добавляет содержимое рабочего каталога в индекс (staging area) для последующего коммита. Эта команда дается после добавления файлов

```
git add <имя файла>
```

### добавляем сохранение

```
git commit -m "Добавили команду удаление"
```

### показать историю коммитов

>Длинный вид
>```
>git log
>```
>
>Укороченный вид
>
>```
>git log --oneline
>```
>

### Перейти к сохранению

```
git checkout c41da22de408f7c00bdcf97403a885c8d4bde2c8
```

### Перейти к ветке мастер

```
git checkout master
```

### Git diff

*git diff* - чтобы увидить разницу

*git diff 309ba16 e5cd452* - увидить разницу между сохранениями

посмотреть в какой мы ветке

git branch
